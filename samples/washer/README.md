# washer 샘플

평와셔(외경 16mm, 내경 4.4mm)를 백라이트 위에 놓고 위에서 찍은 실루엣 영상과 레시피입니다. Basler acA640-120gm으로 직접 찍었습니다(640×480, Mono8, 2026-11-05).

| 파일 | 내용 |
|---|---|
| `washer.recipe.json` | `Ring`(와셔 면적)과 `Hole`(구멍 면적) |
| `images/ok_*.png` | 정상 와셔 6장. 레시피 범위를 정할 때 쓰지 않은 검증 세트 20장에서 번호 순으로 일정 간격을 두고 골랐습니다(파일 번호는 원래 번호). 판정 여유를 보고 고르지 않았습니다 |

결함 영상은 결함 시료를 만든 뒤 추가합니다.

## 촬영 조건

- 조명: 태블릿 흰 화면을 백라이트로 사용(자동 밝기 끔). 산업용 백라이트를 쓰기 전의 임시 구성입니다. 배경 밝기 190~198, 포화 0%
- 카메라: 노출 3000µs, GainRaw 300, 위에서 내려다봄(기울기 약 3°)
- 배율: 0.0394mm/px(외경 16mm 기준), 시야 약 25×19mm, 1mm² ≈ 645px
- 위치: 손으로 놓고, 화면 중심에서 반경 30px(약 1.2mm) 안에 들어올 때만 촬영
- 배경에 보이는 점과 실 모양은 태블릿 화면의 먼지입니다

## 레시피

| 도구 | 설정 | 허용 범위(`MaxArea`) |
|---|---|---|
| `Ring` | 어두운 블롭, 고정 임계값 100, 전체 화면, `MinBlobArea` 200 | 119,823~121,097px |
| `Hole` | 밝은 블롭, 고정 임계값 100, (220,140) 200×200, `MinBlobArea` 200 | 9,332~9,753px |

- 허용 범위는 다른 와셔 20장(조정 세트)의 평균 ± 4σ입니다. σ로는 20장의 표본 표준편차 대신 그 단측 95% 상한(카이제곱, ×1.37)을 썼습니다. 표본이 작으면 σ가 실제보다 작게 나오기 쉽기 때문입니다.
- 조정에 쓰지 않은 다른 와셔 20장(검증 세트)은 모두 OK로 판정됐습니다.
- `MaxArea`는 가장 큰 블롭만 봅니다. 화면 가장자리의 작은 이물은 판정에 들어가지 않고, `MinBlobArea` 200도 같은 목적입니다.
- `Hole` ROI는 위치가 ±28px 흔들려도 구멍이 ROI 안에 남고(여유 15px 이상), ROI 모서리가 와셔 밖으로 나가지 않는 크기입니다.

## 볼 수 있는 것과 없는 것

- **외곽 결손, 구멍 확대 같은 치수 결함**: 허용 범위 폭이 고리 1,274px(약 2.0mm²), 구멍 421px(약 0.65mm²)입니다. 이보다 큰 면적 변화는 범위 안의 어떤 정상품에서 시작해도 범위를 벗어납니다.
  - 정상 영상에 결함을 그려 넣어 확인한 결과(`ok_01`, 고리 면적이 가장 큰 영상):

    | 그려 넣은 결함 | 판정 |
    |---|---|
    | 외곽 결손 1.0mm² | OK |
    | 외곽 결손 1.4mm² | NG(`Ring`) |
    | 외곽 결손 3.1mm² | NG(`Ring`) |
    | 구멍 지름 4.5mm | NG(`Hole`) |
    | 구멍 지름 4.6mm 이상 | NG(`Ring`, `Hole`) |

  - 그려 넣은 결함은 경계가 날카롭습니다. 실물 결함 시료로는 아직 확인하지 않았습니다.
- **굽힘**: 거의 보이지 않습니다. 굽은 쪽은 기울어 짧아 보이는 동시에 렌즈에 가까워져 커 보이는데, 두 효과가 약 6°에서 상쇄됩니다. 직접 굽힌 시료에서 약한 굽힘은 정상과 구별되지 않았고, 센 굽힘은 구멍이 찌그러진 경우만 잡혔습니다.
- **표면 결함**: 실루엣이라 볼 수 없습니다.
- **위치 보정**: 없습니다. 위치가 크게 벗어나면 구멍이 `Hole` ROI에서 잘리거나 와셔가 화면 밖으로 나가 NG가 됩니다.

## 조명 조건

허용 범위가 고리 면적의 ±0.5% 수준이라 조명 밝기에 민감합니다. 영상이 1% 밝아지면 고리 면적이 약 20px 줄어듭니다(이 6장 기준). 검증 세트 정상품 20장의 밝기를 바꿔 본 시험에서는 영상이 10% 밝아지면 4장이 NG로 바뀌었습니다. 이 폴더의 6장은 ±10%에서도 모두 OK였지만, 6장만의 결과입니다.

- 촬영 중에는 밝기를 ±3% 안으로 유지합니다.
- 실시간으로 판정하기 전에 배경 밝기가 190~198이고 포화가 없는지 먼저 확인합니다.
- 조건이 다르면 그 조건에서 정상품 20장으로 범위를 다시 정하고, 이 폴더의 영상도 같은 조건의 영상으로 바꿉니다.
